# ایمیل خود را بررسی کنید

به‌زودی یک لینک تأیید به آدرس ایمیلی که وارد کردید ارسال می‌شود. برای تکمیل اشتراک، روی لینک داخل ایمیل کلیک کنید.

این لینک تا ۲۴ ساعت معتبر است. اگر روی آن کلیک نکنید، به فهرست اضافه نخواهید شد و پیام دیگری دریافت نمی‌کنید.

**ایمیل را دریافت نکردید؟**

- پوشه اسپم را بررسی کنید.
- ایمیل تأیید از آدرس `usreal_war_daily_brief@k1monfared.com` ارسال می‌شود. آن را به مخاطبین اضافه کنید تا پیام‌های بعدی فیلتر نشوند.
- بعد از ۲۴ ساعت می‌توانید فرم را دوباره ارسال کنید. ارسال زودتر، ایمیل جدید تولید نمی‌کند (برای جلوگیری از سوءاستفاده).
